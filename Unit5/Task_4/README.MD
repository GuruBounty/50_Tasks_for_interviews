#### Задача 4 . Слияние интервалов

**Условие задачи**

Дан набор интервалов на числовой прямой. Каждый интервал задаётся парой целых чисел `[l, r]`, где `l ≤ r`.

Нужно **объединить все пересекающиеся интервалы** и вывести итоговый набор непересекающихся интервалов.

Мы считаем интервалы `замкнутыми`:
интервалы `[1,3]` и `[3,5]` пересекаются (имеют общую точку 3) → должны слиться в `[1,5]`.

**Формат ввода**
- Первая строка: `n` — количество интервалов
- Следующие `n` строк: по два числа `l` `r`

**Формат вывода**
- В первой строке: `m` — количество интервалов после слияния
- Далее `m` строк: объединённые интервалы `l` `r` в порядке возрастания `l`

Если `n = 0`, выведите просто: `0`
