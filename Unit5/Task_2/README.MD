#### Задача 2. Два числа с заданной суммой

**Условие задачи**

Дан массив целых чисел `nums` и целое число `target`. Необходимо определить, существуют ли два различных элемента массива, сумма которых равна `target`. Если такие элементы существуют — выведите `YES`, иначе выведите `NO`. Один и тот же элемент массива нельзя использовать дважды.

**Формат ввода**
- Первая строка: целое число `n` — количество элементов массива
- Вторая строка: `n` целых чисел — элементы массива
- Третья строка: целое число `target`

**Формат вывода**
- Выведите `YES`, если существует пара чисел с суммой `target`
- Иначе выведите `NO`
