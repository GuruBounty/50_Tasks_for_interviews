#### Задача 1. Итеративный бинарный поиск

**Условие задачи**

Дан **отсортированный по возрастанию** массив целых чисел `a` длины `n` и целое число `x`.

Необходимо найти **индекс элемента** `x` в массиве, используя **итеративный бинарный поиск**.

Если элемент найден — выведите его индекс (нумерация с 0).  
Если элемент отсутствует — выведите -1.

**Формат ввода**
- Первая строка: целое число `n`
- Вторая строка: `n` целых чисел `a[i]` (строго отсортированы по возрастанию)
- Третья строка: целое число x`

**Формат вывода**
- Один integer — индекс элемента `x`
- Или `-1`, если элемент не найден
