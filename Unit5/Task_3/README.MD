#### Задача 3. Three Sum (упрощённый)

**Условие задачи**

Дан массив целых чисел `a` длины `n`. Необходимо определить, существуют ли три различных элемента массива, сумма которых равна `0`.  
Если такая тройка существует — выведите `YES`, иначе выведите `NO`.  
Использовать один и тот же элемент более одного раза **нельзя**.

**Формат ввода**
- Первая строка: `n`
- Вторая строка: `n` целых чисел `a[i]`

**Формат вывода**
- `YES`, если существует тройка с суммой `0`
- `NO` — иначе
