#### Задача 6 . K-th largest element (Quickselect)
**Условие задачи**

Дан массив целых чисел `a` длины `n` и целое число `k`. Нужно найти `k-й` по величине элемент массива (`k-th` `largest`):
- `k = 1` → самый большой элемент
- `k = n → самый маленький элемент
`
Сортировать массив целиком нельзя.

Нужно решить задачу алгоритмом `Quickselect` (итеративно), со средней сложностью `O(n)`.

**Формат ввода**
- Первая строка: `n`
- Вторая строка: `n` целых чисел `a[i]`
- Третья строка: `k`

**Формат вывода**
- Один `integer — k-й` по величине элемент
- Если `n = 0`, выведите `0`.
