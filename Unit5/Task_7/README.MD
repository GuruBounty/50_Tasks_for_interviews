#### Задача 7 . Скобочная последовательность (stack)

**Условие задачи**

Дана строка `s`, состоящая только из символов: `( ) [ ] { }`. Нужно определить, является ли строка корректной скобочной последовательностью.

Строка считается корректной, если:
- каждой открывающей скобке соответствует закрывающая **того же типа**
- скобки закрываются в **правильном порядке** (последняя открытая закрывается первой)

Выведите:
- `YES` — если строка корректна
- `NO` — иначе

**Формат ввода**

Одна строка s (может быть пустой).

**Формат вывода**

`YES` или `NO`

**Пример**

Ввод:
```
{[()()]}
```

**Вывод:**
```
YES
```
