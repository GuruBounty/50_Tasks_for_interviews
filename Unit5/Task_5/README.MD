#### Задача 5 . Минимум в rotated sorted array

**Условие задачи**

Дан массив целых чисел `a` длины `n`, который был получен из строго возрастающего отсортированного массива циклическим сдвигом (rotation).  
Например: `[1,2,3,4,5]` → `[3,4,5,1,2]`.

Нужно найти минимальный элемент массива.

В массиве нет дубликатов.  
Решение должно быть итеративным (без рекурсии).  

**Формат ввода**
- Первая строка: `n`
- Вторая строка: n целых чисел `a[i]`

**Формат вывода**
- Один integer — минимальный элемент массива
- Если `n = 0`, выведите `0`.
