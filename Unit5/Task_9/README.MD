#### Задача 9 . Сумма подмассива = K (prefix sums + map)

**Условие задачи**

Дан массив целых чисел `a` длины `n` и целое число `K`. Нужно определить, **существует ли непустой подмассив (непрерывный отрезок)**, сумма элементов которого равна `K`.

**Выведите:**
- `YES` — если такой подмассив существует
- `NO` — иначе
  
Подмассив должен быть непустым.  
Решение O(n²) не принимается.

**Формат ввода**
- Первая строка: `n`
- Вторая строка: `n` целых чисел `a[i]`
- Третья строка: целое число `K`

Формат вывода
`YES` или `NO`

|Входные данные |Выходные данные|
|----------------|----------------| 
|5               | YES
|1 2 3 -2 5
|3
