#### Задача 8 . Очередь на двух стеках

**Условие задачи**

Нужно реализовать структуру данных очередь (queue), используя два стека.

**Поддерживаемые операции:**
- `push x` — добавить число `x` в конец очереди
- `pop` — удалить элемент из начала очереди и вывести его
- `front` — вывести элемент из начала очереди (не удаляя)
- `size` — вывести количество элементов
- `empty` — вывести `YES`, если очередь пуста, иначе `NO`

Если операция `pop` или `front` выполняется на пустой очереди — выведите `ERROR`.

**Формат ввода**
- Первая строка: `q` — число команд
- Следующие `q` строк: команды в одном из форматов выше

**Формат вывода**
- Для команд `pop`, `front`, `size`, `empty` выводите результат в отдельной строке.
- Для `push` выводить ничего не нужно.

**Пример**

**Ввод:**
```
9 push 1 push 2 front pop front pop pop empty size
```

**Вывод:**
```
1 1 2 2 ERROR YES 0
```
