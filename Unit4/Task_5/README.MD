#### Задача 5 Упрощённый LRU-кэш (map + container/list)

Нам нужно реализовать LRU cache фиксированной ёмкости: кэш хранит пары `(key → value)` и при переполнении выкидывает **least recently used** (самый “давно не тронутый”) элемент.

**Условие**

**Нам дано:** ёмкость кэша C и последовательность команд.  
**Напиши:** программу, которая поддерживает команды:
- `PUT key value` — положить значение в кэш (если ключ уже есть — обновить значение). Ключ становится **самым недавно использованным**.
- `GET key` — вывести значение по ключу или `-1`, если ключа нет. Если ключ найден — он тоже становится **самым недавно использованным**.

**При этом нужно:**
- если при `PUT` кэш переполнен — удалить **LRU** (самый давно использованный)
- операции должны работать эффективно: `~O(1)` на команду

**При этом нельзя:** хранить порядок “вручную” в срезе с линейными сдвигами.  
**Чтобы сделать — вспомни:** что container/list даёт MoveToFront, PushFront, Back, Remove, а map даст быстрый доступ по ключу.

**Формат ввода**

**Первая строка:**
 
`C` `Q`
- C — ёмкость кэша (0 ≤ C ≤ 200000)
- Q — число команд (0 ≤ Q ≤ 200000)

Далее Q строк команд, каждая в одном из форматов:

- `PUT key value` (key и value — целые числа)
- `GET key`

**Формат вывода**

Для каждой команды `GET` выведите ответ в отдельной строке.
