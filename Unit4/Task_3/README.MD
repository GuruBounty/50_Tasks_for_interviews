#### Задача 3 Top-K самых частых элементов (map + частоты + сортировка)

**Условие**

**Нам дано:**`n` целых чисел и число `k`.

**Напиши:** функцию, которая вернёт `k` наиболее частых чисел.

**При этом нужно:**
- сортировать по **убыванию частоты**
- при равной частоте — по **возрастанию значения** (чтобы ответ был однозначный)
- если уникальных чисел меньше `k`, выведи все уникальные

**При этом нельзя:** сортировать исходный массив и искать частоты “на глаз” — нужна `map`.
**Чтобы сделать — вспомни:** `map[int]int` для частот и `sort.Slice` для сортировки пар.

**Формат ввода**

`n k a1 a2 ... an`

`n` — количество элементов

`k` — сколько элементов нужно вывести

далее `n` целых чисел

**Формат вывода**

Выведите результат через пробел:
- числа в порядке: частота ↓, значение ↑
- если `k == 0` или `n == 0` — пустая строка
