#### Задача 7 Пересечение двух множеств (map как set)

Нам даны **два массива целых чисел**. Нужно найти их **пересечение** — элементы, которые встречаются **и там, и там**.

**Условие**

**Нам дано:**  
  два массива целых чисел A и B.

**Напиши:**  
программу, которая выведет **все числа, присутствующие и в `A`, и в `B`, без повторов**.

**При этом нужно:**
- каждый элемент выводить **один раз**
- результат вывести **в порядке возрастания**
- работать за линейное время

**При этом нельзя:**
- использовать вложенные циклы `O(n²)`
- сортировать оба массива “на всякий случай”

**Чтобы сделать — вспомни:**
- `map[int]struct{} `— это set
- сортировать нужно **результат**, а не входные данные

**Формат вывода**  
Выведите элементы пересечения **через пробел**, в **возрастающем порядке**.  
Если пересечение пустое — выведите пустую строку.
