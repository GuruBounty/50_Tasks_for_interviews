#### Задача 4 Группировка анаграмм (map[string][]string, ключ-канон)

**Условие**

**Нам дано:** `n` слов (только латинские буквы `a..z`, в нижнем регистре).
**Напиши:** программу, которая сгруппирует слова по анаграммам.

**При этом нужно:**
- слова считаются анаграммами, если их отсортированные буквы совпадают (например, eat, tea, ate)
- внутри каждой группы слова должны идти в порядке первого появления во входе
- группы нужно вывести в порядке первого появления “канона” (то есть по моменту, когда встретилась первая строка этой группы)

**При этом нельзя:** 
- сортировать весь вход “просто чтобы было удобно” — порядок важен.
ключ-канон можно получить сортировкой символов слова или подсчётом частот (26 букв).
