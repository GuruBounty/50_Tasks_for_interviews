#### Задача 6 Слияние двух отсортированных массивов (two pointers)

Нам даны **два отсортированных** массива целых чисел. Нужно слить их в один отсортированный массив.

**Нам дано:** два массива `A` и `B`, каждый отсортирован по неубыванию.  
**Напиши:** функцию, которая вернёт массив `C`, полученный слиянием A и B, тоже отсортированный по неубыванию.

**При этом нужно:**
- работать за `O(n+m)`
- не сортировать результат “ещё раз”
- корректно обрабатывать одинаковые элементы

**При этом нельзя:** просто склеить и отсортировать (это O((n+m) log(n+m))).  
Чтобы сделать — вспомни: классический merge из merge sort: два индекса и выбираем меньший.
