####  Задача 8 Методы и pointer receiver: инкремент поля структуры через метод

**Условие**

**Нам дано:** структура `Counter` с одним полем `Value` `int`.  
**Напиши:** метод `Inc(delta int)`, который увеличивает `Value` на `delta`.

**При этом нужно:**
- метод должен реально менять значение в структуре (не в копии)
- обработать несколько команд подряд

**При этом нельзя:**
- возвращать новый `Counter` вместо изменения текущего
- хранить значение как глобальную переменную

**вспомни:**
- `value receiver` получает **копию** структуры
- чтобы менять поля — нужен **pointer receiver** `*Counter`

**Формат ввода**

Первая строка:

q

Далее `q` строк команд двух видов:
- `INC x` — увеличить счётчик на `x`
- `GET` — вывести текущее значение

Начальное значение счётчика равно 0`.

**Формат вывода**

Для каждой команды `GET` выведите текущее значение на отдельной строке.
