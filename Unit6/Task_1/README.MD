#### Задача 1. Оборачивание ошибок и errors.Is

**Условие**

Реализуй функцию: `func loadUser(id int) error`

**Логика функции:**
- Если `id <= 0` → вернуть ошибку `ErrInvalidID`
- Если id == `13` → вернуть **обёрнутую** ошибку `ErrStorage` (обязательно использовать fmt.Errorf с %w)
- Во всех остальных случаях → вернуть `nil`

**Примеры**
```
Ввод  
-1

Вывод  
1 0 0
```
```
Ввод
13

Вывод
0 1 0

(Ошибка распознаётся как ErrStorage, но не равна ей напрямую — значит, была обёрнута)
```
```
Ввод
5

Вывод
0 0 0
```
